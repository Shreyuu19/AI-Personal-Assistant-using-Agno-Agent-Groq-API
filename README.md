# AI-Personal-Assistant-using-Agno-Agent-Groq-API
* Developed an AI-powered personal assistant using Agno Agent and Groq LLM to provide real-time
responses by integrating web search and LLM reasoning.
* Built a responsive web interface using Flask, HTML, CSS, and JavaScript, enabling seamless user
interaction with AI-driven conversations.
* Integrated the DuckDuckGo Search API and Groq API to retrieve up-to-date information and generate
context-aware, intelligent responses.
* Implemented an end-to-end AI application by combining agent orchestration, LLM inference, REST
APIs, and backend integration for efficient query processing.

**Tech:** Python, Flask, HTML, CSS, JavaScript, Agno Agent, Groq API, DuckDuckGo
